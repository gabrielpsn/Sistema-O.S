# Sistema de Ordem de Serviço (O.S.) 🛠️

Este repositório contém um sistema completo para gerenciamento e controle de Ordens de Serviço. O projeto foi estruturado para resolver problemas comuns de fluxo operacional, permitindo a abertura, acompanhamento de status, alocação de técnicos e fechamento de chamados.

### 🚀 Funcionalidades Principais
- **Gerenciamento de Fluxo:** Controle de estados da O.S. (Aberta, Em Andamento, Concluída, Cancelada).
- **Módulo Financeiro/Serviços:** Associação de valores, peças e mão de obra a cada chamado.
- **Histórico de Atendimento:** Registro de interações e auditoria do que foi modificado.

### 🛠️ Tecnologias Utilizadas
- **Backend:** PHP / Laravel
- **Database:** SQL Server / MySQL (ajuste conforme o banco real)
- **Frontend:** JavaScript / Vue.js (ajuste conforme o front real)
